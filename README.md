# 📚 StudySmart Planner

![StudySmart Banner](assets/images/readme/banner.png)

## Interactive Front-End Web Application

StudySmart Planner is a responsive web application developed to help students organise their studies, manage academic tasks, generate personalised study plans and improve productivity through effective time management.

The application has been developed using **HTML5**, **CSS3** and **Vanilla JavaScript** while following responsive web design principles and modern user interface practices. The project allows students to manage their academic workload through a simple and user-friendly interface without requiring any backend services or databases.

StudySmart Planner stores user information locally using **JavaScript Local Storage**, allowing users to save their study information directly in the browser.

# Project Overview

StudySmart Planner is an educational productivity application designed to assist students in organising their studies more effectively.

Many students struggle to manage multiple subjects, assignments, revision sessions and deadlines simultaneously. StudySmart Planner provides a centralised platform where students can organise all of their study activities in one place.

The application combines multiple productivity tools into a single responsive website including:

- Personal Dashboard
- Subject Manager
- Task Manager
- Calendar Planner
- Focus Timer
- Frequently Asked Questions
- About Page
- User Authentication

Instead of switching between different applications for calendars, to-do lists and timers, StudySmart Planner enables students to complete all study planning from one intuitive interface.

The application demonstrates front-end development skills by combining HTML, CSS and JavaScript to create an interactive user experience.

# Login and Registration

The Login page provides secure access to the application while allowing new users to create an account. JavaScript validation ensures users enter valid information before submitting the form.

### Registration Features

Users can:

- Enter their first name
- Enter an email address
- Create a password
- Confirm the password
- Register a new account

When the Sign Up button is pressed, JavaScript checks that:

- No fields are empty.
- The passwords match.
- User information is stored successfully in Local Storage.

A confirmation message is displayed after successful registration.

### Login Features

Returning users can enter their email address and password to access the application.

JavaScript compares the entered details with the information stored in Local Storage. If the credentials are correct, the user is redirected to the dashboard. If the details are incorrect, an error message is displayed.

### Forgot Password

The Forgot Password feature opens a dialog window where users can enter their registered email address.

The current version demonstrates the user interface and validation process by checking whether the email exists in Local Storage.

> **Note:** As this project is a front-end application with no backend server, password reset emails cannot be sent. A real implementation would require a backend service or authentication provider such as Firebase Authentication or EmailJS.

2. Click on the **Settings** tab.
3. From the left navigation menu, select **Pages**.
4. Under **Build and Deployment**, choose:
   - **Source:** Deploy from a branch
5. Select:
   - Branch: **main**
   - Folder: **/ (root)**
6. Click **Save**.
7. GitHub automatically generates a live website link.
8. After a few minutes, the deployed website becomes available.

The live deployment can be accessed using:

```
https://YOUR-USERNAME.github.io/mystudyplanner-project/
```

# Forking the Repository

Forking creates a personal copy of the repository without affecting the original project.

To fork the repository:

1. Log into GitHub.
2. Navigate to the project repository.
3. Click the **Fork** button in the top-right corner.
4. GitHub creates a copy in your own account.

You can now freely modify your copy without changing the original repository.

To clone the repository onto your local machine:
